# Go client parity matrix

Evidence for [README.md](./README.md). Checked against `main` at `bff714ed` (2026-11-05), with the
open pull requests #209, #218, #230 and #235 read. Python paths are under
`clients/python/src/ate_env_rl/`, Go paths under `clients/go/`, unless written in full.

Status words: `parity` (both clients have it), `partial` (part of it, or a Go idiom covers it),
`missing` (not in Go), `ahead` (Go has it and Python does not), `out` (out of scope for this plan).

### Naming note: `exec`, `shell` and `start_process`

The Python direct path names the span of `Env.shell` `ate_env_client.shell` and the span of a
standalone `Env.start_process()` `ate_env_client.start_process`; `Env.shell` turns the inner tracer
off, so the `shell` span has no `start_process` child. The Python fleet handle names its span `exec`
and turns the inner tracer off the same way. The Go client names the span of `Run` `exec` and has no
span on `StartProcess`. [docs/observability.md](../../observability.md) documents `exec` and says a
Go client's spans take the place of the `ate_env_client.*` ones. Decision D6 in the README: Go keeps
`exec` and adds a `start_process` span on `StartProcess`. Renaming or aliasing the Python `shell`
span is a Python follow-up.
