# NeMo Gym provider: acceptance criteria

Status: last checked 2026-11-09 against NeMo Gym `v0.7.0` and `main` at `acb6773`. Unit tests are in
[`integrations/nemo-gym/tests/test_provider.py`](../../../integrations/nemo-gym/tests/test_provider.py)
and run hermetically against the fake ate-env-api in `tests/fakes.py`. E2E tests are in
`tests/test_e2e.py` and run in the Kind E2E job (`hack/ci/e2e.py`).

Status values: **met** (on `main`, with the tests named), **PR** (an open pull request meets it),
**open** (planned, no pull request), **not planned** (decided against; see [README.md](./README.md)
section 3).

Ids run `NG-1` to `NG-33` in document order. The letter in a section title names the group (C, E, S,
I, F, P, V, X) and is not part of the id.
